# The Unorthodox Path

Personal portfolio for an AI/ML engineer and software developer.
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion.

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```

- Edit your name, contact and links in `src/content/site.ts`.
- Edit projects in `src/content/projects.ts`.
- Project rules: `CLAUDE.md`. Design, architecture, content gaps and roadmap: `docs/`.
